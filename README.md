# Electiva Pro I — Parcial 02

Solución en Python de los cinco ejercicios del segundo parcial sobre funciones lambda, clases y objetos, y funciones generadoras.

## Ejercicios

| Punto | Archivo | Enunciado |
|-------|---------|-----------|
| 1 | [`punto1-1.py`](punto1-1.py), [`punto1-2.py`](punto1-2.py) | Explique qué es una función lambda en Python y presente al menos dos ejemplos prácticos. |
| 2 | [`punto2.py`](punto2.py) | Cree una clase llamada Estudiante que tenga como atributos nombre y calificacion. La clase debe tener al menos un método que permita mostrar la información del estudiante y otro método que indique si el estudiante está aprobado o reprobado. Se considera aprobado si la calificación es mayor o igual a 60. |
| 3 | [`punto3.py`](punto3.py) | A partir de una lista de estudiantes con su nombre y calificación, cree una lista de objetos de la clase Estudiante. Luego, el programa debe mostrar todos los estudiantes, mostrar solo los aprobados, mostrar solo los reprobados y ordenar los estudiantes por calificación usando una función lambda. |
| 4 | [`punto4.py`](punto4.py) | Cree una función generadora que produzca números primos hasta un límite n dado. El generador debe validar si n es menor que 2. En ese caso, debe mostrar un mensaje adecuado indicando que no existen números primos menores que 2. |
| 5 | [`punto5.py`](punto5.py) | Cree una función generadora que produzca todas las combinaciones posibles de un conjunto de elementos, dado un tamaño k. Por ejemplo, para el conjunto {1, 2, 3} y k = 2, las combinaciones serían: (1, 2), (1, 3), (2, 3). |

## Ejecución

Requiere Python 3. [`programa.py`](programa.py) reúne los cinco puntos en un menú:

```bash
python3 programa.py
```

Cada punto también es un programa independiente:

```bash
python3 punto4.py
```
